# SIAB Delta-ST Response Compression Design

## Scope

This phase turns the validated Bessel primitive matrices into a trainable,
compact LCAO response space. The zero-order occupied states remain the fixed
ABACUS LCAO reference. The final candidate response space contains the frozen
DZP orbitals and a small number of variable atom-centered orbitals contracted
from Bessel primitives.

The optimization target is the immutable uniform-grid Delta-ST symmetric
response. A Bessel correction space is not retained on the candidate side:
otherwise that correction can hide response missing from the compact LCAO and
the resulting loss would not certify the SOS basis that will be used in
production.

## Physical spaces

For atom `A`, angular momentum `l`, magnetic channel `m`, radial primitive
index `n`, and radial orbital index `p`, define

```text
B_Alnm(r) = j_l(q_ln |r-R_A|) s(|r-R_A|) Y_lm(r-R_A)
Phi_Alpm(C) = sum_n B_Alnm C_lnp.
```

One radial coefficient column `C_l[:,p]` is shared by every `m=-l,...,l`.
This preserves atomic rotational symmetry. The full compact coefficient matrix
is assembled blockwise from the fixed DZP columns and trainable columns:

```text
C_AO = [C_DZP, C_var].
```

The fixed columns are restored bitwise after every optimizer step and have
their gradients zeroed by the established SIAB freeze mechanism. Only
`C_var` is allowed to change.

## Candidate response

Let `Q_occ` project out the fixed occupied LCAO states. In the compact trial
space `A(C)=span(B C_AO)`, assemble the exact uniform-grid contractions and
cross blocks already present in the primitive sidecar:

```text
S(C) = C_AO^H S_B C_AO
H(C) = C_AO^H H_B C_AO
b_i_mu(C) = <Q_occ B C_AO | v_mu^H | psi_i>.
```

After removing numerical zero modes generated by `Q_occ`, solve

```text
[H_Q(C) - eps_i S_Q(C) + i omega_h S_Q(C)] x_i_mu(h)
    = -b_i_mu(C)
M_C(mu,nu;h) = sum_i f_i [b_i_mu(C)^H x_i_nu(h) + c.c.].
```

This is a compact frozen-occupied Galerkin response. It is algebraically equal
to SOS in the same compact virtual space, but it is compared with the uniform-
grid Delta-ST reference rather than with compact-space SOS.

Both sides use one numerical full-Ewald Coulomb transform:

```text
Pi_C(h)   = V_full^(-1/2) M_C(h)   V_full^(-1/2)
Pi_ref(h) = V_full^(-1/2) M_ref(h) V_full^(-1/2).
```

## Differentiable objective

The primary loss is the GreenX-weighted symmetric-response error

```text
L_DeltaST(C) = sum_h w_h ||Pi_C(h)-Pi_ref(h)||_F^2
               / sum_h w_h ||Pi_ref(h)||_F^2.
```

The implementation reports every frequency loss and the trace-log energy
difference, but RPA energy is not the optimization loss because frequency and
matrix-element cancellation can make an incomplete basis look converged.

The first integration reuses the existing `pi_dpsi_joint` composition:

```text
L_total = L_DeltaST
          + lambda_dpsi L_dpsi/L_dpsi,0
          + DFT and dpsi inequality penalties.
```

There is no radial-tail penalty. Diffuse response is physical information.

## Public interfaces

Add `delta_st_response_compression.py` with:

```python
@dataclass(frozen=True)
class DeltaSTCompressionFamilyResult:
    loss: torch.Tensor
    frequency_loss: torch.Tensor
    candidate_pi: torch.Tensor
    reference_pi: torch.Tensor
    candidate_response_m: torch.Tensor
    max_candidate_condition: float
    retained_rank_by_spin: tuple[int, ...]


class FrozenOccupiedDeltaSTCompression:
    def __init__(self, reference, primitive, fixed_ao, coulomb, ...): ...
    def evaluate_matrix(self, coefficients): ...
    def evaluate(self, radial_coefficients): ...
```

`evaluate_matrix` accepts an expanded primitive-to-AO matrix and is the
low-level physics API. `evaluate` accepts the existing SIAB radial coefficient
mapping, repeats each radial column across all magnetic channels, and returns
a `ProjectedPiOptimizationResult` so the established freeze and joint-loss
optimizer can use it without a second optimizer implementation.

The existing orbital assembler is generalized only enough to accept either a
response-v1 object or a primitive-Galerkin object. Existing response-spillage
behavior and column ordering must remain unchanged.

## TDD gates

1. A three-level synthetic system has one occupied direction and two response
   directions. Rotating one variable LCAO toward the missing response lowers
   `L_DeltaST`; the analytic gradient is finite and a sufficiently small step
   lowers the loss.
2. Altering the primitive-to-fixed-AO Hamiltonian cross block changes the loss
   and gradient, proving that occupied-projection/Pulay coupling is not
   silently omitted.
3. Radial assembly shares one coefficient column over every `m`, preserves
   existing response-v1 ordering, and rejects incomplete magnetic blocks.
4. The fixed-DZP freeze path leaves `1s,2s,1p` bitwise unchanged after an
   optimizer step.
5. Protocol mismatches in frequencies, auxiliary channels, occupations,
   full-Coulomb dimensions, kernel, or provenance fail before evaluation.

## First real-data gate

Use the accepted H data: 20-Angstrom cell, 100-Ry grid, 16 fixed GreenX
frequencies, 33 `exx_pca_threshold=1e-4` auxiliary channels, full Coulomb,
and the same fixed TZDP occupied reference. Start from the original H `3s2p`
orbitals, freeze `1s,2s,1p`, and vary only `3s,2p` at unchanged basis size.

Before a full optimization, require:

- finite response loss and gradients;
- zero fixed-DZP coefficient change after a trial step;
- a small accepted step lowers full-frequency `Pi` loss;
- the reported RPA-energy change is treated only as a diagnostic;
- source revision, sidecar hashes, and Coulomb provenance match the accepted
  reference.

The first basis is promoted to an ABACUS SOS test only after the optimizer also
passes the existing DFT/dpsi constraints. H2 transferability and raw SOS-RPA
binding are subsequent independent gates.

## Non-goals

- No new Bessel roots, angular shells, or auxiliary basis in this phase.
- No claim that compact Galerkin/SOS equality proves basis completeness.
- No optimization against a scalar RPA binding energy.
- No replacement of the production uniform-grid Delta-ST solver.
