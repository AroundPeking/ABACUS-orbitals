# C Atom-Solid Balanced Response Optimization

## Physical target

The C basis is accepted by the ordinary all-band SOS binding energy

\[
E_{\rm bind}^{\rm SOS}
=E_{\rm C\,atom}^{\rm SOS}-\frac{1}{2}E_{\rm C_2\,solid}^{\rm SOS},
\]

not by a solid-only response loss.  This follows the accepted H workflow:
the isolated fragment and the bonded environment must enter basis training
together because a small error in either absolute RPA correlation energy can
remain large in their difference.

## Training families

The first joint C campaign uses two physical families.

1. `C_atom`: the accepted spin-polarized C atom target with integer
   occupations `Nup=3`, `Ndown=1` and all available imaginary frequencies.
2. `C_solid`: the diamond primitive-cell periodic Galerkin datasets at the
   training q representatives.  The existing `q1` and `q2` datasets train the
   basis; `q3` remains held out.

The fixed SG15 DZP prefix `2s2p1d` remains bitwise unchanged.  Only added
response shells are optimized.

## Balanced objective

Each family is normalized independently before the families are combined:

\[
L_F(C)=
\frac{\sum_{d\in F}w_d\sum_j w_j
\lVert\Pi_d(C,i\omega_j)-\Pi_d^{\rm ref}(i\omega_j)\rVert_F^2}
{\sum_{d\in F}w_d\sum_j w_j
\lVert\Pi_d^{\rm ref}(i\omega_j)\rVert_F^2},
\qquad
L_{\rm joint}=\frac{L_{\rm C\,atom}+L_{\rm C\,solid}}{2}.
\]

For the already available atom target, a first-order-wavefunction residual may
be used only as a temporary interface gate.  The production joint objective
uses projected atomic `Pi`, which additionally requires the matching
`STERNHEIMER_SIAB_SOURCE_V1.dat`.  This source is generated by the source-only
route without solving any new Sternheimer equations.  Atom and solid frequency
grids may differ because each family is normalized before averaging.

The family average, rather than one global numerator and denominator, prevents
the larger solid response matrices from suppressing the atom objective.

## Numerical gates

Before an expensive full-BZ SOS calculation, a candidate must satisfy all of
the following:

- fixed-prefix occupied capture is not degraded;
- atom and solid family losses both improve, with neither hidden by their
  average;
- held-out solid `q3` improves;
- the overlap condition remains comparable to the original TZDP basis;
- no extreme solid-only virtual-energy tail is introduced;
- radial smoothness and kinetic norms pass the existing shell gates.

The final physical gate keeps the pseudopotential, geometry, `4^3` k/q mesh,
six-frequency SOS protocol, product-PCA threshold `1e-4`, exact-grid full
periodic Coulomb kernel, and LibRPA revision fixed.  The candidate is accepted
only when

\[
\left|E_{\rm bind}^{\rm SOS}-E_{\rm bind}^{\Delta\rm ST}\right|
<0.1\ {\rm kcal\,mol^{-1}\,C^{-1}},
\]

where the converged Delta-ST value is a fixed external reference and is not
recomputed during basis optimization.
